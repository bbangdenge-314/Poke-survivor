# 🌟 포켓 서바이버 (Poke Survivor)

**▶ 바로 플레이하기: [https://bbangdenge-314.github.io/Poke-survivor/](https://bbangdenge-314.github.io/Poke-survivor/)**

포켓몬의 감성으로 즐기는 **로그라이크 서바이벌** 게임입니다. 26마리의 플레이어블 포켓몬을 골라 7개의 테마 스테이지에서 몰려오는 적을 뚫고 살아남으세요. 레벨업으로 기술을 조합하고, 인게임 진화 퀘스트를 달성해 진화하며, 최종 보스를 쓰러뜨리면 스테이지 클리어입니다.

---

## 🎮 게임 소개

- **장르**: 탑다운 로그라이크 서바이벌 (뱀서라이크)
- **한 판 길이**: 12~15분 (스테이지별 상이)
- **목표**: 제한 시간까지 생존한 뒤 등장하는 **최종 보스** 처치
- **성장**: 한 판 안에서는 레벨업·각성·초각성·진화, 판이 끝나면 코인으로 **영구 강화**
- **해금**: 메타 퀘스트를 달성하면 새 포켓몬·스테이지·패시브·필드 아이템이 열립니다

### 조작법

| 플랫폼 | 조작 |
| --- | --- |
| PC | `W A S D` 또는 방향키로 이동 · 공격은 자동 |
| PC | `ESC` 또는 `P` — 일시정지 (미니맵·조합표·옵션) |
| 모바일 | 화면을 드래그해 가상 조이스틱 이동 · 공격은 자동 |
| 모바일 | 우측 상단 일시정지 버튼 — 일시정지 / 옵션 |

> 기술은 자동으로 발동됩니다. 이동과 레벨업 선택, 진화 퀘스트 달성에 집중하세요.

## 🧬 주요 시스템

### 1. 플레이어블 포켓몬 26종
이상해씨·파이리·꾸부기·피카츄·이브이·팬텀·루카리오·한카리아스·갸라도스·잠만보부터 리자몽·거북왕·이상해꽃·메타그로스·다크라이·지라치·루기아·뮤츠·레쿠쟈·뮤, 그리고 괴력몬·후딘·라프라스·망나뇽·마기라스·에이스번까지 총 **26종**.

각 포켓몬은 고유 능력(시그니처), 친화 기술, 타입 보너스, 전용 기술 강화를 가집니다. 이브이는 5가지 분기 진화(샤미드·쥬피썬더·부스터·에브이·블래키)를 선택할 수 있습니다.

### 2. 인게임 진화 퀘스트
레벨만 오르면 자동 진화하던 방식을 없애고, **판 안에서 퀘스트를 달성해야 진화**합니다.

- 예: `적 380마리 · 2분 생존` → 1차 진화, `적 1300마리 · 보스 2마리 · 상자 4개` → 2차 진화
- 캐릭터마다 조건이 다릅니다 (처치 수, 엘리트/보스 처치, 무피격 시간, 기술 명중 횟수, 상자 획득 등)
- 난이도: 1차 진화는 대략 2~3분, 2차 진화는 5~6분 이후, 메가/거다이는 7~9분 이후에나 열립니다. 초반에 바로 진화하지 않도록 처치 수·생존 시간·보스/엘리트 조건이 크게 올라가 있습니다.
- HUD 좌측 하단과 일시정지 화면에 **현재 진화 퀘스트 진행도**가 실시간으로 표시됩니다
- 퀘스트를 달성하면 자동으로 진화하며 전용 연출이 재생됩니다

### 3. 메가진화 · 거다이맥스
최종 진화를 마친 일부 포켓몬은 **전용 초고난도 퀘스트**를 달성하면 메가진화/거다이맥스합니다.

- 조건 예: `적 2600마리 + 보스 3마리 + 엘리트 8마리 + 30초 무피격` (캐릭터·등급별로 수치가 다릅니다)
- 메가진화: 이상해꽃·리자몽 X·거북왕·팬텀·루카리오·한카리아스·갸라도스·후딘·마기라스·메타그로스·뮤츠 Y·레쿠쟈
- 거다이맥스: 피카츄·이브이·잠만보·라프라스·괴력몬·에이스번
- 실제 메가/거다이 스프라이트 + 전용 오라 + 거대화 + 공격력/체력 대폭 상승

### 4. 이로치 · 전설 · 환상 포켓몬
- 확률적으로 **이로치** 포켓몬이 등장하며, 처치하면 추가 보상
- 스테이지마다 **환상 포켓몬**이 등장해 도망치기 전에 잡으면 별의모래와 보물상자를 줍니다
- 플레이어도 이로치로 시작할 수 있습니다(보유 시)

### 5. 기술 22종 + 각성 + 초각성
**액티브 기술 Lv.6 + 짝 패시브 Lv.1 → 각성 기술**로 진화합니다. (레벨업 카드 또는 보물상자)
각성 기술은 이름·색·이펙트가 완전히 달라집니다. 예: 번개 연쇄, 화염 회오리, 물기둥, 잎날 폭풍, 유령 장판, 뼈다귀 부메랑, 회오리 흡입, 문포스, 프리즘 캐논.

**초각성(각성 + 각성)**: 각성 기술 2개를 보유하면 레벨업/상자에서 **초각성 카드**가 등장해 두 기술이 하나의 궁극기로 합쳐집니다.

| 초각성 | 재료 |
| --- | --- |
| 🌩️ 폭풍의 심판 | 천둥의 심판 + 불대문자 |
| 🌊 빙하 해일 | 하이드로펌프 + 블리자드 |
| 🌳 세계수의 심판 | 리프스톰 + 유성군 |
| 🕳️ 영원한 어둠 | 섀도다이브 + 원한의 늪 |
| 💠 무한의 파동 | 파동폭발 + 역린 |
| 🌋 천지개벽 | 대지진 + 기가프레스 |

로비의 **[조합표]** 화면에서 1단계(각성)와 2단계(초각성) 트리를 한눈에 볼 수 있습니다.

### 6. 7개 테마 스테이지
| # | 스테이지 | 특징 | 최종 보스 |
| --- | --- | --- | --- |
| 1 | 🌱 관동 초원 | 초원 타일·연못·나무, 기본 적 | 뮤츠 |
| 2 | ⛰️ 은빛 동굴 | 용암 웅덩이·수정·보호막 바위 적 | 레쿠쟈 |
| 3 | ☁️ 하늘 제단 | 구름·기둥·별, 돌진형 비행 적 | 레쿠쟈 |
| 4 | 👻 보라타운 유령숲 | 안개·묘비·고목, 순간이동 유령 | 기라티나 |
| 5 | 🌊 심해 아쿠아 신전 | 산호·거품·심해 적, 탄막·회복 지원 | 가이오가 |
| 6 | 🌋 태초의 마그마 화산 | 용암·불씨·화산 적, 자폭·돌진 | 그란돈 |
| 7 | 🌌 뒤틀린 시공의 틈 | 균열·파편·전 기믹 총출동 | 아르세우스 |

각 스테이지는 전용 배경 타일과 지형 오브젝트, 전용 적 조합, 전용 보스 패턴을 가지며, 이전 스테이지 클리어 퀘스트로 해금됩니다.

### 7. 적 기믹
단순 추적 외에 다양한 기믹이 있습니다.

- **돌진형**: 예고선을 그은 뒤 빠르게 돌진
- **탄막형**: 거리를 유지하며 부채꼴 탄막
- **보호막/탱커형**: 데미지를 크게 줄이는 보호막(공격하면 파괴됨)
- **분열형**: 죽으면 두 마리로 분열
- **자폭형**: 사망 시 폭발해 지속 피해 장판 생성
- **지원형**: 주변 적을 회복시키고 이동속도를 올려줌
- **순간이동형**: 플레이어 근처로 순간이동해 기습
- 보스는 **탄막·돌진·빔·소환** 패턴을 사용합니다

### 8. 필드 아이템 · 미니맵 · 옵션
- 필드 아이템: 오랭열매, 자석 오브, 코인 주머니, 충격파 폭탄(퀘스트 해금), 수호의 방패(퀘스트 해금), 가속의 깃털(퀘스트 해금), 경험치 사탕
- 파괴 가능한 상자·바위·수정에서 아이템과 코인 획득
- 미니맵으로 보스·환상·상자·아이템 위치 확인
- **옵션**: 효과음 / 울음소리 / **화면 흔들림 ON·OFF** / **시야·캐릭터 크기(넓게·기본·크게·아주 크게)**
  - 모든 설정은 `localStorage`에 저장되어 다음 접속에도 유지됩니다
  - 기본값은 "넓게"로, 캐릭터가 조금 작게 보이고 맵을 넓게 볼 수 있습니다

### 9. 메타 퀘스트 해금 시스템
로비의 **[퀘스트]** 화면에서 26개의 업적을 확인하고 보상을 수령하세요.

- 누적 처치, 보스 처치, 스테이지 클리어, 각성/초각성/메가진화, 상자 획득, 최고 레벨, 플레이 시간 등
- 보상: 코인 / 포켓몬 해금 / 스테이지 해금 / 패시브 해금 / 필드 아이템 해금
- 진행도는 자동 저장되며, 수령 가능한 퀘스트는 로비에서 바로 알려줍니다

### 10. 영구 강화 상점
코인으로 공격력·체력·이동속도·공격속도·자석·경험치·코인·방어력·부활·이로치 확률·행운·시작 기술을 영구 강화합니다. 판이 끝나도 유지되며 `localStorage`에 저장됩니다.

## 🛠️ 기술 정보

- 순수 HTML/CSS/JavaScript (프레임워크·빌드 도구 없음), ES Modules
- 캔버스 2D 렌더링, 포켓몬 스프라이트는 [PokéAPI sprites](https://github.com/PokeAPI/sprites) 사용
- 사운드는 WebAudio로 실시간 합성, 울음소리는 PokéAPI cries
- 진행 상황은 브라우저 `localStorage`(`pokeSurvivor.save.v4`)에 저장

### 로컬 실행

```bash
git clone https://github.com/bbangdenge-314/Poke-survivor.git
cd Poke-survivor
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> ES Module을 사용하므로 `file://`로 직접 열지 말고 간단한 HTTP 서버로 실행하세요.

### 프로젝트 구조

```
index.html          # 화면 마크업 (HUD, 오버레이)
styles.css          # 파스텔 테마 UI
src/main.js         # 부트스트랩·입력·게임 루프
src/game.js         # 게임 엔진 (전투·적 AI·진화·초각성·렌더)
src/data.js         # 포켓몬/기술/적/스테이지/퀘스트 데이터
src/ui.js           # 로비·도감·조합표·퀘스트·HUD UI
src/save.js         # localStorage 저장·메타 진행·퀘스트
src/sprites.js      # 스프라이트 로딩
src/audio.js        # 효과음 합성
```
