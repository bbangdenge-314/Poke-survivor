# 🌟 포켓 서바이버 (Poke Survivor)

**▶ 바로 플레이하기: [https://bbangdenge-314.github.io/Poke-survivor/](https://bbangdenge-314.github.io/Poke-survivor/)**

포켓몬의 감성으로 즐기는 **로그라이크 서바이벌** 게임입니다. **스타터 5종**(이상해씨·파이리·꼬부기·피카츄·이브이)으로 시작해, **104종의 포켓몬을 저마다 다른 전용 퀘스트로 하나씩 해금**하며 7개의 테마 스테이지에서 몰려오는 적을 뚫고 살아남으세요. 기술 22종 + 각성 22종 + **초각성 25종**의 조합이 준비되어 있습니다. 레벨업으로 기술을 조합하고, 인게임 진화 퀘스트를 달성해 진화하며, 최종 보스를 쓰러뜨리면 스테이지 클리어입니다.

---

## 🎮 게임 소개

- **장르**: 탑다운 로그라이크 서바이벌 (뱀서라이크)
- **한 판 길이**: 12~15분 (스테이지별 상이)
- **목표**: 제한 시간까지 생존한 뒤 등장하는 **최종 보스** 처치
- **성장**: 한 판 안에서는 레벨업·각성·초각성·진화, 판이 끝나면 코인으로 **영구 강화**
- **해금**: 스타터 5종을 제외한 104종의 포켓몬은 **전용 퀘스트**를 달성해 해금합니다. 스테이지·패시브·필드 아이템도 퀘스트 보상으로 열립니다

## 🧬 주요 시스템

### 1. 플레이어블 포켓몬 109종 (1~9세대)
1세대 이상해씨·파이리·꼬부기·피카츄·이브이부터 9세대 마스카나·라우드본·파라블레이즈·타부자고·코라이돈·미라이돈까지 **총 109종**이 등장합니다.

처음부터 열려 있는 것은 **스타터 5종**(이상해씨·파이리·꼬부기·피카츄·이브이)뿐이고, 나머지 **104종은 각자의 전용 퀘스트**로 해금됩니다.
- 예: 독침붕 「독침의 맹세」 = 독 타입 적 200마리 처치 / 리자몽 「불꽃의 날개」 = 불꽃 타입 적 450마리 처치
- 예: 뮤츠 「유전자의 왕」 = 뒤틀린 시공의 틈 클리어 + 메가·거다이 2회 / 뮤 「모든 것을 배우는 자」 = 도감 60종 포획 + 각성 6회
- 누적 처치·타입별 처치·기술별 처치·스테이지 클리어·보스/엘리트·상자·이로치·환상 포획·각성/초각성/메가·거다이·무피격 생존·누적 코인·도감 등 **17가지 목표 유형**을 조합해 104개 퀘스트가 전부 다릅니다

- 세대별 분포: 1세대 38 · 2세대 18 · 3세대 17 · 4세대 12 · 5세대 4 · 6세대 3 · 7세대 4 · 8세대 7 · 9세대 6 (합 109)
- 전설·환상 포켓몬(뮤츠·루기아·가이오가·그란돈·디아루가·아르세우스·자시안·코라이돈 등)은 후반 난이도(◆◆◆~◆◆◆◆) 퀘스트로 해금됩니다
- 각 포켓몬은 **고유 능력(시그니처)**, 친화 기술 3종, 타입 숙련 보너스, 전용 기술 강화를 가집니다
- 일부는 **메가진화/거다이맥스** 폼까지 실제 진화 체인대로 이어집니다 (예: 핫삼→메가핫삼, 개굴닌자, 버터플→거다이버터플)
- 이브이는 5가지 분기 진화(샤미드·쥬피썬더·부스터·에브이·블래키)를 선택할 수 있습니다

**찾기 쉬운 선택 화면**: 109마리가 한 화면에 들어오지 않으므로 선택 화면에 필터를 붙였습니다.
- 🔍 이름 검색(한글·영문·진화 전 이름 모두)
- 세대 필터(전체/1~9세대, 세대별 마리 수 표시)
- 타입 필터(18타입, 가로 스크롤)
- 해금 상태 필터(전체 · 해금 · 잠금 · ✦ 이로치)
- 잠긴 포켓몬 카드에는 **해금 퀘스트 진행도 바**가 표시되고, 카드를 누르면 **퀘스트 이름·조건·현재 진행도·보상**이 팝업으로 보입니다
- 현재 조건에 맞는 마리 수가 제목에 실시간 표시됩니다

### 2. 인게임 진화 퀘스트
레벨만 오르면 자동 진화하던 방식을 없애고, **판 안에서 퀘스트를 달성해야 진화**합니다.

- 예: `적 380마리 · 2분 생존` → 1차 진화, `적 1300마리 · 보스 2마리 · 상자 4개` → 2차 진화
- 캐릭터마다 조건이 다릅니다 (처치 수, 엘리트/보스 처치, 무피격 시간, 기술 명중 횟수, 상자 획득 등)
- 난이도: 1차 진화는 대략 2~3분, 2차 진화는 5~6분 이후, 메가/거다이는 7~9분 이후에나 열립니다. 초반에 바로 진화하지 않도록 처치 수·생존 시간·보스/엘리트 조건이 크게 올라가 있습니다.
- HUD 좌측 하단과 일시정지 화면에 **현재 진화 퀘스트 진행도**가 실시간으로 표시됩니다
- 퀘스트를 달성하면 자동으로 진화하며 전용 연출이 재생됩니다

### 3. 메가진화 · 거다이맥스
최종 진화를 마친 일부 포켓몬은 **전용 초고난도 퀘스트**를 달성하면 메가진화/거다이맥스합니다.

- 조건 예: `적 2600마리 + 보스 3마리 + 엘리트 8마리 + 30초 무피격` (캐릭터·등급별로 수치가 다릅니다)
- 메가진화 41종 · 거다이맥스 9종 (각 포켓몬의 실제 폼 기준, 예: 메가핫삼·메가보만다·메가번치코·메가가디안·거다이버터플·거다이아머까오)
- 캐릭터 선택 화면의 미리보기에서 진화 체인과 함께 메가/거다이 폼 스프라이트를 확인할 수 있습니다
- 실제 메가/거다이 스프라이트 + 전용 오라 + 거대화 + 공격력/체력 대폭 상승

### 4. 이로치 · 전설 · 환상 포켓몬
- 확률적으로 **이로치** 포켓몬이 등장하며, 처치하면 추가 보상
- 스테이지마다 **환상 포켓몬**이 등장해 도망치기 전에 잡으면 별의모래와 보물상자를 줍니다
- 플레이어도 이로치로 시작할 수 있습니다(보유 시)

### 5. 기술 22종 + 각성 + 초각성
**액티브 기술 Lv.6 + 짝 패시브 Lv.1 → 각성 기술**로 진화합니다. (레벨업 카드 또는 보물상자)
각성 기술은 이름·색·이펙트가 완전히 달라집니다. 예: 번개 연쇄, 화염 회오리, 물기둥, 잎날 폭풍, 유령 장판, 뼈다귀 부메랑, 회오리 흡입, 문포스, 프리즘 캐논.

**초각성(각성 + 각성)**: 각성 기술 2개를 보유하면 레벨업/상자에서 **초각성 카드**가 등장해 두 기술이 하나의 궁극기로 합쳐집니다. 각성 22종이 **모두 최소 하나의 초각성 조합**에 쓰이며, 초각성 25종은 각자 완전히 다른 전투 로직(연쇄 번개, 결정 감옥, 역병 장판, 궤도 폭격, 소용돌이 흡입, 거울 파편 폭풍 등)을 가집니다.

### 7. 적 기믹
단순 추적 외에 다양한 기믹이 있습니다.

- **돌진형**: 예고선을 그은 뒤 빠르게 돌진
- **탄막형**: 거리를 유지하며 부채꼴 탄막
- **보호막/탱커형**: 데미지를 크게 줄이는 보호막(공격하면 파괴됨)
- **분열형**: 죽으면 두 마리로 분열
- **자폭형**: 사망 시 폭발해 지속 피해 장판 생성
- **지원형**: 주변 적을 회복시키고 이동속도를 올려줌
- **순간이동형**: 플레이어 근처로 순간이동해 기습
- 보스는 **탄막·돌진·빔·소환** 패턴을 사용합니다

- 각 퀘스트는 여러 조건을 동시에 표시합니다 (예: `뒤틀린 시공의 틈 클리어` + `메가·거다이 2회`) — 조건마다 진행 바가 따로 표시됩니다
- 캐릭터 해금 퀘스트는 **난이도 ◆~◆◆◆◆** 로 나뉘어 있고, 수령하면 캐릭터가 즉시 열리며 코인도 함께 지급됩니다
- 보상: 포켓몬 해금 / 스테이지 해금 / 패시브 해금 / 필드 아이템 해금 / 코인
- 진행도는 자동 저장되며, 로비 하단에 **다음 해금** 포켓몬과 진행도가 표시됩니다

### 10. 영구 강화 상점
코인으로 공격력·체력·이동속도·공격속도·자석·경험치·코인·방어력·부활·이로치 확률·행운·시작 기술을 영구 강화합니다. 판이 끝나도 유지되며 `localStorage`에 저장됩니다.

## 🛠️ 기술 정보

- 순수 HTML/CSS/JavaScript (프레임워크·빌드 도구 없음), ES Modules
- 캔버스 2D 렌더링, 포켓몬 스프라이트는 [PokéAPI sprites](https://github.com/PokeAPI/sprites) 사용
- 사운드는 WebAudio로 실시간 합성, 울음소리는 PokéAPI cries
- 진행 상황은 브라우저 `localStorage`(`pokeSurvivor.save.v5`)에 저장
- v4 세이브는 자동으로 v5로 이전됩니다: 코인·영구강화·스테이지 개방·클리어·도감·이로치·설정은 유지되고, 캐릭터는 스타터 5종 + 이미 수령한 퀘스트 보상만 남긴 뒤 **퀘스트 해금 구조**로 전환됩니다 (첫 실행 시 안내 팝업)

### 로컬 실행

```bash
git clone https://github.com/bbangdenge-314/Poke-survivor.git
cd Poke-survivor
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> ES Module을 사용하므로 `file://`로 직접 열지 말고 간단한 HTTP 서버로 실행하세요.
